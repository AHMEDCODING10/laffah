# 🚀 Laffah System - دليل التشغيل السريع (Quick Start Guide)

يحتوي هذا الملف على الأوامر اللازمة لتشغيل أنظمة الباك إند (Backend) وخوادم البث المباشر (WebSockets) لضمان عمل تطبيق "لفّة" بكافة ميزاته (خاصة ميزة التتبع الحي للكابتن).

## 🛠️ أوامر تشغيل السيرفرات (Backend)
للحصول على تجربة متكاملة يجب فتح **3 نوافذ Terminal مختلفة** في مسار مشروع الباك إند (`pixelmind/backend`)، وتشغيل التالي:

### 1️⃣ النافذة الأولى: سيرفر API الأساسي
هذا السيرفر يعالج جميع طلبات الـ HTTP العادية (مثل تسجيل الدخول، البحث عن المواقع، الخ).
```bash
php artisan serve
```

### 2️⃣ النافذة الثانية: سيرفر التتبع الحي (Laravel Reverb)
هذا السيرفر مسؤول عن معالجة اتصالات الـ WebSockets عالية الأداء والتي تستخدم في تتبع الكابتن المباشر على الخريطة بدون تأخير (Real-time).
```bash
php artisan reverb:start --debug
```
*(ملاحظة: وضع الـ debug يساعدك على رؤية الإحداثيات وهي تُرسل مباشرة على شاشة التيرمنال).*

### 3️⃣ النافذة الثالثة: محاكي الكابتن (للتجربة والاختبار)
قمنا ببناء سكريبت صغير يحاكي حركة دراجة نارية في صنعاء لإثبات فعالية التتبع الحي. قم بتشغيله **بعد** أن تفتح شاشة التتبع في تطبيق الجوال:
```bash
php simulate_tracking.php
```

## 📱 أوامر تشغيل التطبيق (Frontend - Flutter)
في مسار مشروع الموبايل (`pixelmind/laffah`)، تأكد دائماً من تحديث المكتبات وتنظيف المشروع عند إجراء تغييرات كبيرة:

### تنظيف المشروع (إن لزم الأمر)
```bash
flutter clean
flutter pub get
```

### إصلاح وتجميل الأكواد تلقائياً
```bash
dart fix --apply
```

### تشغيل التطبيق
```bash
flutter run
```

## 🌟 الميزات التي تمت إضافتها مؤخراً
- **التتبع الحي فائق الدقة (Glide Movement):** الدراجة النارية الآن تنزلق بنعومة على الخريطة وتلتف (Rotation) حسب اتجاه الكابتن بفضل `TweenAnimationBuilder` و `Reverb`.
- **تسعير المسارات بناءً على الطرق الحقيقية:** تم استبدال الحساب المباشر بخدمة `OSRM API` المفتوحة والمجانية بنسبة 100% لمعرفة المسافة الفعلية ووقت الرحلة الحقيقي.
- **البحث الاحترافي عن المواقع:** تم دمج `Photon API` (بديل Google Maps) للبحث عن أي موقع وإرجاع الإحداثيات بدقة عالية وسرعة فائقة دون أي تكاليف (مجاني تماماً).
- **تحسين واجهة المستخدم:** إعادة تنسيق شريط البحث العلوي، وجعله متجاوباً ومتوافقاً مع أفضل تطبيقات النقل.
