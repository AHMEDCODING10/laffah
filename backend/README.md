# 🚀 نظام لَفَّة - لوحة التحكم الشاملة (Laffah Backend & Admin Panel)

مرحباً بك في المستودع الرسمي الخاص بالخوادم ولوحة التحكم لتطبيق **لَفَّة**. هذا النظام هو القلب النابض الذي يدير التطبيق، ويربط بين المستخدمين (الركاب) والكباتن بسلاسة وفي الوقت الفعلي.

**لوحة التحكم أصبحت الآن جاهزة بالكامل 100% بتصميم Premium مذهل وبتقنيات عالمية.**

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

النظام مبني باستخدام أحدث التقنيات لضمان الأمان، السرعة، وقابلية التوسع:

- **إطار العمل الأساسي:** Laravel 11 (PHP 8.2+)
- **بناء الواجهات التفاعلية بدون إعادة تحميل:** Laravel Livewire 3
- **تصميم لوحة التحكم:** مخصص بالكامل (Vanilla CSS + CSS Variables) مع دعم كامل للوضع الداكن المتقدم (Deep Slate Dark Mode).
- **قواعد البيانات:** MySQL (عبر Eloquent ORM).
- **تتبع الخرائط (Live Maps):** Leaflet.js مع دعم مزودي خرائط CartoDB (Dark Matter للوضع الداكن، Voyager للوضع الفاتح).
- **نظام الحماية والتوثيق:** Laravel Sanctum (لواجهات الـ API الخاصة بتطبيقات الجوال).
- **الأيقونات والرسوميات:** أيقونات SVG حديثة وتأثيرات زجاجية (Glassmorphism).

---

## 📱 الربط مع التطبيق (API Integration)

يعمل هذا النظام كـ **RESTful API Backend** لتطبيق "لَفَّة" المبني بـ Flutter.
يتم التعامل مع:
- **المصادقة:** تسجيل دخول الركاب والكباتن عبر نظام التوكن (Sanctum Tokens).
- **البيانات الحية:** تحديث مواقع الكباتن، إدارة الرحلات والمحفظة المالية.
- **التوثيق (Verification):** قيام الكابتن برفع (بطاقة الهوية + رخصة المركبة) من التطبيق ليتم مراجعتها وقبولها عبر هذه اللوحة.

---

## 🎛️ صفحات لوحة التحكم وعملها

تم تصميم لوحة التحكم لتغطي كافة احتياجات إدارة النظام، وتتكون من الصفحات التالية:

1. **الرئيسية (Dashboard):** 
   - إحصائيات سريعة، عدد المستخدمين، والرحلات النشطة.
2. **الخريطة الحية (Live Map):** 
   - تتبع أماكن الكباتن في الوقت الفعلي مع مؤشرات نابضة (Pulsing Markers).
3. **المستخدمون والركاب:** 
   - إدارة حسابات الركاب، حظر الحسابات، ومتابعة الحالات.
4. **الكباتن (Captains):** 
   - إدارة حسابات السائقين، والاطلاع على التقييمات والأرباح.
5. **طلبات التوثيق (Verification Requests):** 
   - مراجعة الهوية ورخصة المركبة التي تم رفعها من التطبيق للتوثيق بضغطة زر.
6. **سجل الرحلات (Trips):** 
   - أرشيف كامل للرحلات (مكتملة، ملغية، جارية) مع التكلفة والتفاصيل.
7. **المعاملات المالية (Transactions):** 
   - تتبع الشحن، الخصومات، والأرباح في المحافظ.
8. **طلبات السحب (Withdrawals):** 
   - مراجعة طلبات سحب الأرباح من الكباتن وتنفيذها.
9. **مركز الإشعارات (Notifications):** 
   - شريط انزلاقي جانبي أنيق يظهر الإشعارات الحية بأسلوب زجاجي.

## 💎 مميزات واجهة المستخدم الفريدة (UI/UX)

- **دعم الأجهزة المحمولة:** الجداول تتحول تلقائياً إلى "بطاقات" (Mobile Cards) عند تصفح النظام من الجوال.
- **تأثيرات حركية (Micro-animations):** تأثيرات الهيكل العظمي للتحميل (Skeleton Loaders)، وإضاءة البطاقات (Glow Effects).
- **تجاوب الأزرار:** تصميم أزرار ترقيم الصفحات (Pagination) بشكل أنيق ونظيف.
