# 🏍️ لَفَّة (Laffah) - تطبيق النقل والتوصيل المبتكر

مرحباً بكم في المستودع الرسمي لتطبيق الموبايل **لَفَّة (Laffah)**. تطبيق لَفَّة هو منصة حديثة ومبتكرة لخدمات النقل الذكي وتوصيل الطرود بواسطة الدراجات النارية في اليمن. يوفر التطبيق واجهات منفصلة ومتخصصة لكل من الركاب والكباتن لضمان تجربة مستخدم سلسة وفعّالة.

---

## 📱 ميزات وتطبيقات النظام (Components)

التطبيق مقسم برمجياً وبصرياً ليخدم فئتين أساسيتين:

1. **تطبيق الراكب (Passenger App):**
   - **الخريطة التفاعلية:** تحديد نقطة الانطلاق والوصول بسهولة مع ميزة تحديد المواقع الجغرافية الدقيقة.
   - **حجز الرحلات:** طلب رحلات فورية للدراجات النارية مع معرفة السعر التقديري مسبقاً.
   - **خدمة الطرود (Parcels):** نظام خاص بطلب توصيل الطرود والطلبيات مع متابعة حية لمسار الطرد.
   - **الأماكن المحفوظة:** حفظ الأماكن المفضلة (المنزل، العمل) للوصول السريع.

2. **تطبيق الكابتن (Captain App):**
   - **استقبال الطلبات:** واجهة مخصصة لقبول طلبات الركاب والطرود القريبة عبر الخريطة.
   - **المحفظة والأرباح:** تتبع الأرباح اليومية، المكافآت (Bonuses)، وعمولة المنصة.
   - **توثيق الحساب (Verification):** واجهة مخصصة لالتقاط ورفع بطاقة الهوية وكرت المركبة للمراجعة والتوثيق من قِبل إدارة النظام.
   - **حالة الاتصال:** التحكم في حالة توفر الكابتن (متصل / غير متصل) لاستقبال الطلبات.

3. **الميزات المشتركة:**
   - **التصميم الجمالي (UI/UX):** واجهات عصرية (Glassmorphism)، دعم كامل للوضع الداكن (Dark Mode).
   - **متعدد اللغات (Localization):** دعم كامل للغتين العربية (RTL) والإنجليزية (LTR).
   - **تتبع حي ومباشر:** استخدام خرائط تفاعلية وتواصل لحظي عبر WebSockets.

---

## 🛠️ التقنيات المعمارية المستخدمة

تم تصميم التطبيق وفق أفضل الممارسات البرمجية لضمان الأداء، قابلية التوسع، وسهولة الصيانة:

- **إطار العمل (Framework):** Flutter (Dart)
- **إدارة الحالة (State Management):** BLoC / Cubit لضمان فصل المنطق البرمجي عن واجهة المستخدم.
- **بنية المشروع (Architecture):** Clean Architecture وتقسيم الميزات (Feature-based structure).
- **الشبكات والتواصل (Networking):** 
  - HTTP / Dio للتواصل مع RESTful APIs التابعة لنظام Laravel.
  - Laravel Echo / WebSockets للتتبع الحي وإشعارات الرحلات.
- **الخرائط (Maps):** Flutter Map (OpenStreetMap) لتوفير خرائط دقيقة بدون تكاليف إضافية.
- **تحديد المواقع (Geolocation):** Geolocator لجلب موقع المستخدم والكابتن الحي وتتبعه أثناء الرحلة.
- **الحقن والاعتماديات (DI):** GetIt لإدارة التبعيات وحقنها بفعالية.
